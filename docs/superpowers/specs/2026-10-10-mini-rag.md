# 선정 APAC 사건 공개 근거 미니 RAG

사용자가 승인한 범위: 국방 지식 전체 챗봇 대신 선정한 사건의 수집 원문을 재검색하는 모듈을 직접 만들고 팀에 보완을 요청한다.

- 사건을 명시적으로 등록하고 사건 ID 안에서만 검색한다. 등록은 자료의 사건 적합성 검증을 뜻하지 않는다.
- 기존 `frame` 수집 JSON과 앱 보고서의 원문을 받아 SQLite에 저장한다. 원문 문단·문서 ID, 정확한 인용과 문자 위치를 반환한다.
- 첫 버전은 외부 의존성 없이 문자 n-gram/단어 기반 BM25 검색이다. 기존 LLM의 언어별 검색어를 받아 한국어 질문과 외국어 원문을 연결한다. 임베딩 의미 검색·자동 번역은 후속 작업이다.
- Tavily 관련도, 검색 점수, 출처 등급·가중치, LLM 관련도는 각각 보존한다. 가중치를 곱해 진위 확률을 만들지 않는다.
- 게시일과 사건일을 구분하고 국가·언어·날짜 조건을 적용한다. 조건에 필요한 날짜 미확인은 제외한다.
- 동일 본문·명시된 재인용 그룹의 결과 중복을 억제한다. 도메인 수로 독립 근거 수를 계산하지 않는다.
- 요약만 있는 자료와 가상 자료는 기본 검색에서 제외한다. 본문 잘림·정제·날짜 미확인도 함께 표시한다.
- API, `/rag` 실행 화면, 가상 예시 JSON, 팀원용 연동·보완 문서를 제공한다. 답변 생성·통계·진위 판정은 기존 담당 모듈의 책임이다.
- 현재 기능 브랜치에서 별도 RAG 파일을 추가한다. 사용자 기존 변경·다른 담당 모듈을 덮어쓰거나 자동 커밋하지 않는다.
