# Mini RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 선정 사건의 수집 원문을 저장하고 질문에 맞는 인용 근거를 반환하는 실행 가능한 미니 RAG를 만든다.

**Architecture:** 별도 자료형·SQLite 저장 및 BM25 검색·수집 어댑터·FastAPI 라우터로 분리한다. 기존 앱에는 라우터 등록만 추가하고 독립 화면에서 사건 등록, JSON 적재, 원문 검색을 제공한다.

**Tech Stack:** Python 3.12+, 기존 Pydantic/FastAPI, 표준 SQLite, 기본 JavaScript.

**Spec:** `docs/superpowers/specs/2026-10-10-mini-rag.md`

## Global Constraints

- 외부 의존성·유료 API 호출 없이 동작한다.
- 사건 등록은 자료의 사건 적합성 검증을 뜻하지 않는다.
- 임베딩 의미 검색·자동 번역은 후속 작업이다.
- 사용자 기존 변경·다른 담당 모듈을 덮어쓰거나 자동 커밋하지 않는다.

## Review Focus

- 다른 사건의 같은 문서 ID가 섞이지 않아야 한다.
- 수정 적재·재시작 이후 오래된 청크가 남지 않아야 한다.
- 요약·가상·날짜 미확인 제외 사유가 누락되지 않아야 한다.
- 서로 다른 점수·가중치가 검색 순위를 왜곡하지 않아야 한다.
- 검색 문자열과 원문에 들어 있는 명령·HTML을 실행하지 않아야 한다.
